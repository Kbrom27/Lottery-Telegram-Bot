============================================================
        LOTTERYBOT FOR WINDOWS — CLIENT QUICK GUIDE
============================================================

1. HOW TO INSTALL & UPGRADE
   - Download and double-click "LotteryBot-Setup.exe".
   - Follow the Windows Setup Wizard (choose install location
     and optionally check "Create a desktop icon").
   - After installation, shortcuts are created in your Start Menu
     and (if selected) on your Desktop:
       * Start LotteryBot  — Starts the service & opens Web UI
       * Stop LotteryBot   — Cleanly stops the background service
       * Open in Browser   — Opens http://127.0.0.1:8000
       * Uninstall         — Standard Windows uninstaller
   - A small ticket icon also appears in your Windows System
     Tray (bottom-right near the clock). Right-click it anytime
     to open the dashboard, start/stop the bot, or exit.
   - UPGRADING TO A NEWER VERSION:
     Simply run the newer "LotteryBot-Setup.exe" into the same
     install folder. Only the program files are upgraded — all
     your existing settings (config.json), issued tickets and
     payments (lottery.db), and screenshots in "lottery_data"
     remain completely untouched!

2. FIRST-TIME SETUP (IN YOUR WEB BROWSER)
   On first launch, fill out the Setup & Settings page:
   - Campaign / Bot Name
   - Telegram Bot Token (create a bot via @BotFather -> /newbot)
     Click "Verify Token" to confirm it connects.
   - Admin Telegram ID(s) (message @userinfobot on Telegram)
   - Ticket Price in ETB (e.g. 100 ETB). Multiples (200, 300, 400...)
     automatically issue 2, 3, 4... lottery numbers.
   - CBE Account Number (required for instant CBE QR verification)
   - Telebirr Number & Account Name (optional)
   - Click "Save Settings & Start Bot Service".

3. USING THE WEB DASHBOARD
   - Start / Stop Button: Top-right bar starts or pauses the bot.
   - Live Metrics: Shows Total Birr Received, Lottery Numbers
     Issued, Unique Participants, and Pending Reviews.
   - Issued Numbers Table: Search who holds which ticket numbers
     (toggle between "By Person" and "Every Ticket Row").
   - Download Buttons:
     * Download Lottery Holders Excel (.xlsx) — includes full names,
       bank payer names, usernames, and grouped summary per holder.
     * Download Financial Summary Report (.xlsx)
     * Download Draw CSV / Public List CSV
   - Pending Reviews Tab: Inspect screenshot receipts and approve
     or reject manually if needed.
   - Draw Winners Tab: Provably fair SHA-256 winner selection.

4. WHERE YOUR DATA IS SAVED (PRESERVED ON UPGRADE)
   - All user data is stored separately inside the "lottery_data"
     folder inside your install directory (containing config.json,
     lottery.db, logs, and saved receipt screenshots).
   - Upgrading by running a new "LotteryBot-Setup.exe" never
     deletes or resets "lottery_data". Back up this folder
     periodically!

5. OPTIONAL ADD-ONS
   - Cropped / Telebirr Screenshots (Text OCR):
     Full CBE screenshots with QR codes work automatically out of
     the box. If you also want automatic text OCR on Telebirr or
     cropped screenshots, install Tesseract-OCR for Windows and
     restart LotteryBot.exe.
   - Automatic Phone SMS Forwarding:
     If you use an Android SMS Forwarder app on your receiving SIM
     phone, enable "Allow LAN access" in Settings, restart the app,
     and point the app to: POST http://<YOUR-PC-IP>:8000/sms
     with header X-Secret: <your SMS secret from Settings>.
